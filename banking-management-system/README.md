# Banking Management System (C++)

Console banking application — Sqrock IT Solutions C++ Internship, Phase 1 Task 2.

## Features
- Create account (Savings/Current) with 4-digit PIN
- PIN-protected login
- Deposit, withdraw (overdraft protection), transfer between accounts
- Transaction history per account (timestamped)
- Admin listing of all accounts
- Data persisted to `accounts.txt` and `transactions.txt`

## Build & run
```bash
g++ -std=c++17 -o bank banking.cpp
./bank
```

## Concepts
Core C++ · OOP (class `Account`) · STL · file handling · validation.
